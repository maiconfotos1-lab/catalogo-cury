# Catálogo Cury RJ — Maicon Cavalcanti

Catálogo estático em HTML/CSS/JavaScript, pronto para GitHub Pages.

## Como atualizar
1. Edite `js/data.js`.
2. Cada empreendimento é um objeto dentro de `projects`.
3. Publique o conteúdo deste diretório em um repositório público do GitHub.
4. Em Settings > Pages, selecione Deploy from branch / main / root.

## Observação
Este primeiro pacote usa informações públicas encontradas nas páginas da Cury para três empreendimentos e deixa a estrutura pronta para expansão. Preços, estoque, condições comerciais e imagens devem ser conferidos/atualizados antes da publicação comercial.
